# Baú dos Baixinhos

## 1. Descrição do Sistema (Mini-Mundo)

O **Baú dos Baixinhos** é um site de comércio eletrônico voltado para a venda de produtos variados, como vasos, roupas, calçados, livros e utensílios. O projeto foi desenvolvido para a Web, com foco em apresentar os produtos de forma organizada e visualmente agradável, permitindo que os usuários conheçam os itens disponíveis e acessem informações sobre a loja e suas redes sociais. O site é responsivo e pode ser acessado em diferentes dispositivos, mantendo uma boa experiência de navegação.

## 2. Tecnologias e Funcionalidades

- **Tecnologias:** HTML5, CSS3, JavaScript.  
- **Funcionalidades:**  
  - Exibição de produtos em grid;  
  - Botão de compra redirecionando para contato via link externo;  
  - Modal de visualização ampliada das imagens;  
  - Links para redes sociais;  
  - Mapa interativo para localização da loja;  
  - Layout responsivo para diferentes tamanhos de tela.

## 4. Procedimentos de Execução Local

1. Clonar o repositório ou descompactar o arquivo `.zip`.  
2. Acessar a raiz do projeto e executar o arquivo `index.html`.  
3. O sistema não requer dependências de servidor externas para funcionamento básico.
